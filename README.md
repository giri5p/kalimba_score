# カリンバ楽譜メーカー

初心者向けに、五線譜の下に **ドレミ / カリンバ数字譜 (1,2,3…) / CDEFGAB** の3段を並べて表示する楽譜作成ページです。
完全にローカルで動きます（サーバー不要・通信なし）。

## 使い方

`public/index.html` をダブルクリックしてブラウザで開くだけです。

```
kalimba/
├── public/                     ← 公開されるのはこのフォルダの中だけ
│   ├── index.html              ← これを開く
│   ├── app.js
│   ├── about.html              ← このサイトについて（作った経緯・できること）
│   ├── _headers                ← 配信時のキャッシュ設定
│   └── vendor/vexflow-bravura.js  ← 楽譜描画ライブラリ（同梱・オフラインで動作）
├── wrangler.jsonc              ← Cloudflare へのデプロイ設定
└── start.cmd / server.js       ← ローカルでマイクを使うとき（下記）
```

## このサイトについて（about.html）

作った経緯、できること・できないこと、データの扱いをまとめた 1 ページです。
楽譜の下の「このサイトについて」リンクと、チュートリアル1ページ目から開けます。
連絡先を載せたい場合は `about.html` のコメント部分に書き足してください。

## はじめて開いた人へ（チュートリアル）

はじめてページを開くと、使い方の説明が自動で出ます（全6ページ）。
あとからでもツールバーの **❓ 使い方** でいつでも読み直せます。
`←` `→` キーでページ送り、`Esc` で閉じられます。

スマホで開いたときは、1ページ目に「この幅では見る専用です」という案内が足されます。

## 曲の保存と共有

ツールバーの **📁 曲・保存** を押すと、曲の保存パネルが開きます。

- **この名前で保存** … ブラウザの中に名前を付けて何曲でも保存できます。ファイルは使いません
- **一覧** … 保存した曲を「開く」「削除」できます
- **🔗 リンクをコピー** … 曲の中身をそのまま URL に埋め込みます。
  そのリンクをスマホに送って開けば、同じ楽譜がそのまま表示されます（数十音で 200〜600 文字ほど）
- **JSONで書き出し / 読み込む** … パソコンでファイルとして持っておきたいとき用

保存先は端末ごと（ブラウザごと）です。パソコンとスマホの間で曲を移すときはリンクを使ってください。
リンクで開いた曲に手を加えたあとは、読み込み直しても自分の編集のほうが残ります。

## スマホで見る

**画面の幅だけで自動的に切り替わります**（760px 以下で「見るための表示」）。切り替えボタンはありません。
パソコンでウィンドウを狭くしても同じ表示になり、広げれば編集画面に戻ります。

見るための表示では:

- 下の入力パネル（音符の長さ・編集・鍵盤・操作説明）は**まるごと消えます**
- 上は **☰ / ▶ 最初から / ▶ ここから / 🔔 / 🔇 / 📁 / ❓** の1行だけになります（文字は畳まれてアイコンだけ）
- **☰** を押すと、曲名・テンポ・拍子・1段の小節数・カリンバのキー数・
  ドレミ/数字/CDE の表示切り替えが下に開きます。もう一度押すと閉じます
- 譜面は画面幅に合わせて自動で段組みされます
- 音符の書き換えはできません（画面を触っても譜面は変わりません）
- 音符をタップして **▶ ここから** を押せば、その場所から再生できます

## 広告を入れる（忍者AD MAX）

`public/index.html` の中ほど、コメントで囲まれた場所に空の枠があります。

```html
<!-- ▼▼▼ 広告枠（忍者AD MAX） ▼▼▼ … -->
<div id="ad" class="adbox"></div>
<!-- ▲▲▲ 広告枠ここまで ▲▲▲ -->
```

忍者AD MAX で発行された広告タグを、この `div` の**中にそのまま貼り付けて** push すれば反映されます。

```html
<div id="ad" class="adbox">
  <script src="https://adm.shinobi.jp/s/xxxxxxxxxxxx"></script>
</div>
```

- 場所は**楽譜の下、「このサイトについて」リンクの上**です
- タグを貼るまでは高さ 0 で、何も表示されず場所も取りません
- 枠を増やしたいときは、この `div` ごとコピーして `id` を `ad2`, `ad3` … に
- **印刷と PNG 書き出しには入りません**
- 忍者AD MAX のタグは `document.write` を使うことがあるため、JavaScript で
  あとから差し込まず、HTML に直接書いてください

## インターネットに公開する（Cloudflare Pages）

HTML と JavaScript だけの静的サイトなので、ビルドは要りません。

1. このフォルダを GitHub のリポジトリとして push します（`main` ブランチ）
2. Cloudflare のダッシュボードで **Workers & Pages → 作成 → Pages → Git に接続**
3. そのリポジトリを選び、設定は次のとおり
   - フレームワークプリセット: **なし (None)**
   - ビルドコマンド: **空欄**
   - ビルド出力ディレクトリ: **/**（リポジトリの直下）
4. 保存すると `https://<プロジェクト名>.pages.dev` で公開されます。
   以降は `main` に push するたびに自動で更新されます

公開サイトは HTTPS なので、**スマホでもマイク入力が使えます**（`start.cmd` はローカル用なので不要になります）。
`gakuhu/` フォルダ（自分で作った楽譜の JSON）は `.gitignore` で公開対象から外してあります。
公開したい場合は `.gitignore` の該当行を消してください。

## 入力モード

ツールバーの「数字キー・鍵盤」で、`1`–`7` キーとカリンバ鍵盤クリックの動作を切り替えます
（`M` キーでも切り替わります）。

- **音程を変更** … 選択中の音符の音程を変える。カーソルは動きません。既存の譜面の直しに向きます
- **音符を追加** … 選択中の音符の**後ろに**新しい音符を追加して、そこへカーソルを移します。
  `1234567` と打てばそのまま ド レ ミ ファ ソ ラ シ になります（`0` なら休符が追加されます）。
  長さは直前の音符を引き継ぐので、`←` `→` で長さを決めてから打ち込むと速いです
- **リズム入力** … 「音符を追加」に加えて、**押した間隔から長さも決めます**。
  弾くつもりのリズムでキーを叩くと、テンポに合わせていちばん近い音符の長さ
  （16分〜全音符・付点あり）に丸められます

どのモードでも、`↑` `↓` は選択中の音符の音程を変え、`Shift`+鍵盤クリックは和音の追加／解除です。

### リズム入力のコツ

- 先にツールバーの **テンポ** を実際に弾く速さに合わせてください。長さはこのテンポを基準に決まります
- **🔔 拍**（メトロノーム）を鳴らしながら叩くとズレにくくなります
- 長さが付くのは「1つ前の音符」です。最後の音符は直前の長さを引き継ぐので、
  必要なら `←` `→` かホイールで直してください
- カーソルを動かしたりモードを変えたりすると、間隔の計測はリセットされます

## 複数選択

連続した音符をまとめて選んで、一括で編集できます。

**選ぶ**

| 操作 | 動作 |
|---|---|
| 楽譜上をドラッグ | なぞった範囲を選択 |
| `Shift` + 音符クリック | いまの位置からそこまで選択 |
| `Shift` + `←` `→` | 1音ずつ範囲を広げる／狭める |
| `Shift` + `Home` / `End` | 先頭 / 末尾まで選択 |
| `Ctrl+A` | 全選択 |
| `Esc` | 選択を解除 |

**まとめて編集**

- `↑` `↓` … 選択した音符すべての音程を上下（`Shift`+で1オクターブ）＝**一括の音階変更**。休符はそのまま残ります
- `←` `→` … 選択した音符すべての長さを変更
- `R` 休符 / `.` 付点 / `T` タイ / `C` 和音 … 選択範囲すべてに適用（先頭の音符の状態に合わせて全部そろえます）
- `Delete` … 選択範囲をまとめて削除

**コピー・貼り付け**

| キー | 動作 |
|---|---|
| `Ctrl+C` | コピー |
| `Ctrl+X` | 切り取り |
| `Ctrl+V` | 貼り付け |

貼り付けは、範囲を選んでいればその範囲を**置き換え**、選んでいなければ**カーソルの後ろに挿入**します。
貼り付けた音符がそのまま選択された状態になるので、続けて `↑` `↓` で移調すると便利です。
どの操作も `Ctrl+Z` でまとめて戻せます。

## 和音（複数の音）の直し方

和音のうち **1音だけ**を選んで直せます。

1. 直したい**音符の玉（たま）をクリック**します（キーボードなら `[` `]` で選びます）。
   選んだ音に青い丸印が付き、下のステータスに「ミ だけを選択中」と出ます
2. そのまま操作します

| 操作 | 動作 |
|---|---|
| `↑` `↓` | **その音だけ**上下に動かす |
| `1`–`7` / 鍵盤クリック | **その音だけ**差し替える |
| `Delete` | **その音だけ**和音から外す（音符自体は残る） |
| `Esc` | 1音の選択を解除して、和音まるごとの操作に戻す |

丸印が付いていないときは、今までどおり和音の全部の音が動きます。

そのほか和音の操作:

- `C` / **和音+** … いまの一番上の音の3度上を足す
- `Shift+C` / **和音−** … 選んでいる音を外す（選んでいなければ一番上の音）
- `Shift` + 鍵盤クリック … その音を和音に足す／外す

## マウス操作

- 楽譜上の**音符をクリック**して選択
- **音符の上でホイールを回す**と長さを変更（上に回す＝長く / 下に回す＝短く）。
  回し始めるとその音符を掴んだままになるので、音符の位置がずれても続けて回せます。
  1回の操作は `Ctrl+Z` でまとめて取り消せます
- 下の**カリンバのキーをクリック**で音程指定（`Shift`+クリックで和音に追加／解除）

音符の上以外ではホイールは通常どおりページのスクロールになります。

## 数字譜・音名の表記

数字譜と音名は同じオクターブ記号でそろえてあります。

| | 基準オクターブ | 1つ上 | 2つ上 |
|---|---|---|---|
| 数字譜 | `1` `2` `3` … | `1*` `2*` … | `1**` `2**` … |
| 音名 | `C` `D` `E` … | `C*` `D*` … | `C**` `D**` … |

基準オクターブ（無印）は 17キーカリンバのいちばん低い `C`（ドの段）です。
下のオクターブは `.1` / `.C` のように `.` を付けます。

和音は**音を縦に積んで**表示します（上が高い音）。休符には何も書きません。

```
   ソ        ← 和音の上の音
   ミ
   ド

   5*        ← 数字譜も同じ並び
   3*
   1*

   G*        ← 音名も同じ並び
   E*
   C*
```

休符を入れたいときは **`0` キー**、または画面下の鍵盤のいちばん左にある **「0 休符」キー**を使います
（「音符を追加」「リズム入力」モードでは休符が追加され、「音程を変更」モードでは今の音符が休符になります）。

## マイク入力（弾いた音から楽譜を作る）

ツールバーの **🎤 マイク** を押すとブラウザがマイクの許可を求めるので、許可すると録音が始まります。
カリンバを弾くと、拾った音が**単音の音符として次々に楽譜へ追加**されます。**■ 停止**で終わりです。

- 先に **テンポ** を合わせてください。音の長さはテンポを基準に丸められます
- 音量バーを見ながら **感度** を調整してください。拾いすぎるときは右へ、拾えないときは左へ
- **🔔 拍** を鳴らすとリズムが安定しますが、クリック音をマイクが拾うので**イヤホン推奨**です
- 録音した分は `Ctrl+Z` でまとめて取り消せます
- 音声はすべてブラウザの中だけで処理され、どこにも送信されません

**できないこと・苦手なこと**

- **和音は拾えません**（単音のみ）。同時に鳴らすと片方だけ、または誤検出になります
- 残響・雑音の多い場所、弱すぎる音は苦手です
- 半音はカリンバの音階に丸められます
- あくまで下書きです。おかしなところは後から手で直す前提でお使いください

### マイクが使えないとき

`index.html` を直接開いた状態（`file://`）ではブラウザがマイクを許可しないことがあります。
その場合は **`start.cmd` をダブルクリック**してください。
`http://localhost:8731/` として同じページが開き、マイクが使えるようになります
（Node.js が必要です。黒いウィンドウは開いている間だけ動くもので、閉じれば終了します）。

## 再生

- **▶ 最初から**（`Shift+Space`）… 曲の頭から鳴らします
- **▶ ここから**（`Space`）… 選択中の音符から鳴らします

鳴っている側のボタンが **■ 停止** に変わります。再生中にもう一方を押すと、その位置から鳴らし直します。

再生中は、**鳴り終わったところまでの背景が水色に塗られていきます**（シークバー）。
先頭には濃い水色の縦線が出て、いまどこを鳴らしているかがわかります。

### 🔇 無音（一緒に弾く練習用）

**🔇 無音** を押しておくと、**音を出さずに譜面の進行だけ**が動きます。
自分でカリンバを弾きながら、いまどこを弾いているかを目で追うためのモードです。

- シークバーの進み方・段ごとのスクロール追従は通常の再生と同じです
- **🔔 拍**（メトロノーム）と組み合わせると、クリックだけ聞きながら練習できます
- 設定は次に開いたときも残ります

## 譜面の見え方

- **1段** で 1 行に並べる小節数を選べます（初期値 4小節）。
- すべての小節を同じ幅で描き、段の先頭に確保する記号ぶんの幅もそろえてあるので、
  **小節線も音符も、段をまたいで縦にぴったり揃います**。
  入力途中の小節も引き伸ばされず、すでに入れた音符は本来の拍の位置に並びます。
- 画面が狭いときは、選んだ数より少ない小節数に自動で減ります。
- **再生中**は、鳴っている段が画面の上端に来るように自動でスクロールします（先の譜面が見えるように）。
  演奏中に場所を見失わないよう、急に飛ばずに短いアニメーション（0.16〜0.4秒）で動きます。
  途中で手でスクロールすると、そこでアニメーションは止まります。
  **編集中**はスクロールしません。カーソルが画面の外へ出たときだけ追いかけます。

## 🎵 ノーツ練習（演奏補助）

ツールバーの **🎵 練習** を押すと、音ゲーのように**ノーツが降ってくる画面**になります。

この画面は **`/practice`** という別の URL になります。
リロードしても練習画面のまま開きますし、ブラウザの「戻る」でも楽譜ページに戻れます。
曲をリンクで共有しているときは `/practice#s=…` のように曲もそのまま付いてきます。

- レーンの並びは**実物のカリンバと同じ**（中央が低い音、左右に交互）
- 下の黄色い線に届いた瞬間が、その音を弾くタイミングです
- ノーツの**色**はオクターブ（青＝基準／緑＝1つ上／紫＝2つ上）
- カリンバは押さえ続ける奏法がないので、ノーツの長さは音符の長さによらず一定です
  （音の長さは、ノーツどうしの間隔で分かります）
- 和音は同じ高さに並んで降ってきます
- 弾いた音の判定や採点はしません。あくまで「いつ・どのキーを弾くか」の目安です

画面上の操作:

| | |
|---|---|
| **▶ 開始 / ⏸ 一時停止 / ▶ 再開** | `Space` でも切り替えできます。一時停止した位置から続けられます |
| **■** | 曲の先頭に戻します |
| **画面を上下にドラッグ** | 再生位置を動かします。ノーツをつかんで下へ引くと先へ進みます。鳴らしている途中でも、離したところから続きます |
| **テンポ** | ここで変えると楽譜側にも反映されます |
| **速さ** | ノーツの落ちる速さ（1〜10）。遅くすると先まで見えます |
| **🔔** | メトロノーム |
| **🔇** | 音を出さない（自分で弾くとき用） |
| **✕ 閉じる** | `Esc` でも閉じられます（URL も楽譜ページに戻ります） |

スマホでも使えます。譜面を読むより、こちらのほうが弾きやすいかもしれません。

## 書き出し・印刷

いずれも **📁 曲・保存** のパネルの中にあります。

- 編集中の内容はブラウザに自動保存され、次に開いたとき復元されます
- **PNG** … 楽譜を画像として書き出し
- **印刷** … ブラウザの印刷から紙 / PDF へ（A4 縦・ツールバーは印刷されません）

## 補足

- 対応音域はツールバーの「カリンバ」で切り替えます（17 / 21 / 15 / 10 / 8キー）。
  音域を狭くすると範囲外の音は端の音に丸められます（`Ctrl+Z` で戻せます）。
- カリンバは半音を持たない楽器なので、入力できるのは C メジャーの全音階のみです。
- 小節線は入力した音符の長さから自動で引かれます。
- タイは「次の音符にも同じ高さの音がある」ときだけ効きます。和音では**共通する音ごとに1本ずつ**
  引かれ、再生でもその音だけが伸びます（共通しない音は次の音符で鳴らし直します）。
  小節をまたぐタイもそのまま引かれ、段をまたぐ場合は行末と行頭に分けて描かれます。
